# Security

This repository is a demonstration/example of platform engineering work. It is not a production service and is not distributed as open source software.

The security controls are designed to show a defensible delivery path for Kubernetes workloads:

- signed container images and attestations
- SBOM generation
- vulnerability scanning
- admission policy
- restricted workload defaults
- GitOps-oriented runtime state

Please do not include secrets, credentials, or sensitive environment details in issues, pull requests, or discussions related to this repository.
